Вход в панель

Здесь можно добавлять свои проекты на сайт. Войти может только тот, у кого есть токен доступа.

Как получить токен
  1. Откройте GitHub и зайдите в Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Нажмите Generate new token и придумайте название.
  3. В разделе Repository access выберите Only select repositories и укажите репозиторий сайта.
  4. В Permissions → Repository permissions найдите Contents и поставьте Read and write.
  5. Нажмите Generate token и скопируйте значение, оно показывается один раз.

Токен нигде не хранится на сайте. Он остаётся только в вашем браузере и работает как пароль.
