# Помогите Кристине выиграть

Мобильная браузерная игра в вертикальном формате: помогите Кристине выиграть до 120 минут массажа. Стартовое меню разделено на три коротких окна: описание истории, правила и противники. Перед каждым раундом появляется стеклянная карточка в стиле iOS с фотографиями игроков и их бросками; аватары противников увеличены на время подготовки, затем уменьшаются, когда начинаются атаки. Снаряды летят от аватара к ногам Кристины. Подпись Кристины и подсказка управления исчезают с началом раунда.

## Как запустить

Откройте `index.html` в браузере или выложите содержимое этой папки на GitHub Pages.

## Как выложить игру на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория файл `index.html`, папку `assets` и этот файл `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите **Deploy from a branch**, затем ветку `main` и папку `/(root)`, нажмите **Save**.
5. После публикации откройте выданную GitHub Pages ссылку на телефоне.

На GitHub Pages публикуются файлы сайта. Если репозиторий открыт, фотографии персонажей тоже будут доступны посетителям сайта.

## Управление

- Телефон: ведите пальцем по экрану, чтобы двигать Кристину.
- Компьютер: зажмите левую кнопку мыши и перемещайте курсор по игровому полю.
- Имя игрока сохраняется в браузере на этом устройстве и подставляется при следующем открытии игры.
- Ловите 12 золотых секунд на каждом уровне. После каждого уровня появляется окно о заработанной минуте массажа; победа — после 120-го уровня.
- Перед началом раунда игра подробно показывает, кто участвует и что бросает. Гурбан бросает бутылки с водой, которые разбиваются на лужу и осколки, и хорошо заметные какашки 💩. Крестено бросает скользкие банановые кожурки и какашки. Макпал кидает колбаски, Настя — банки с монетами.
- При попадании предмета в Кристину раунд заканчивается. Брошенные мимо предметы остаются на поляне до конца уровня; разбитые бутылки оставляют воду и осколки.
- На уровнях 1–4 броски остаются спокойными. После 3-го уровня Гурбан зовёт Крестено; затем появляются Макпал и Настя. Пятый раунд сложный, шестой — самый жёсткий, особенно после девятой пойманной секунды. Между уровнями показываются разные короткие истории о том, кто позвал нового противника и что он бросает.
