# Секунды на весь день

Мобильная браузерная игра в вертикальном формате. Перед каждым уровнем аватары стоят неподвижно 10 секунд, на экране показаны противники и то, что они бросают. После отсчёта аватары начинают двигаться и ускоряться. Кита перемещается по поляне целиком.

## Как запустить

Откройте `index.html` в браузере или выложите содержимое этой папки на GitHub Pages.

## Как выложить игру на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория файл `index.html`, папку `assets` и этот файл `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите **Deploy from a branch**, затем ветку `main` и папку `/(root)`, нажмите **Save**.
5. После публикации откройте выданную GitHub Pages ссылку на телефоне.

На GitHub Pages публикуются файлы сайта. Если репозиторий открыт, фотографии персонажей тоже будут доступны посетителям сайта.

## Управление

- Телефон: удерживайте стрелки внизу экрана или ведите пальцем по поляне.
- Компьютер: клавиши `←` / `→` или `A` / `D`.
- Ловите 12 золотых секунд на каждом из шести уровней. После каждого уровня появляется окно о заработанной минуте массажа.
- Гурбан бросает бутылки с водой и какашки. Крестено бросает банановые кожурки и какашки. Макпал бросает колбаски. Настя бросает банки с монетами.
- При попадании предмета в Киту раунд заканчивается. Брошенные мимо предметы остаются на поляне до конца уровня; разбитые бутылки оставляют воду и осколки.
- На уровнях 1–3 бросает Гурбан. На уровне 4 присоединяется Крестено, на 5 — Макпал, на 6 — Настя. Броски ускоряются, последние секунды шестого уровня самые трудные.
