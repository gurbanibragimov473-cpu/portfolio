# Секунды на весь день

Мобильная браузерная игра в вертикальном формате. Кита перемещается по поляне целиком; круглые фото-аватары нападающих движутся сверху по своим дорожкам и бросают предметы со своих текущих позиций.

## Как запустить

Откройте `index.html` в браузере или выложите содержимое этой папки на GitHub Pages.

## Как выложить игру на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория файл `index.html`, папку `assets` и этот файл `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите **Deploy from a branch**, затем ветку `main` и папку `/(root)`, нажмите **Save**.
5. После публикации откройте выданную GitHub Pages ссылку на телефоне.

На GitHub Pages публикуются файлы сайта. Если репозиторий открыт, фотографии персонажей тоже будут доступны посетителям сайта.

## Управление

- Телефон: удерживайте стрелки внизу экрана или ведите пальцем по поляне.
- Компьютер: клавиши `←` / `→` или `A` / `D`.
- Ловите 12 секунд на каждом из шести уровней. После каждого уровня игра показывает, что заработана ещё одна минута массажа.
- В бутылках бывает вода или мультяшная грязь. При попадании в Киту раунд заканчивается; при падении бутылка разбивается, а лужа и осколки остаются до конца уровня.
- На уровнях 1–3 бросает Злой Сашка. На уровне 4 присоединяется Крестено, на 5 — Макпал, на 6 — Настя.
- С каждым уровнем броски учащаются и ускоряются. Последние секунды шестого уровня самые трудные.
