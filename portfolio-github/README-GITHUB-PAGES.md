# Публикация сайта на GitHub Pages

В этой папке находятся готовые файлы сайта. `index.html` лежит в корне, а каталоги `css`, `js`, `img` и `video` должны быть загружены вместе с HTML-файлами. Не переносите видео отдельно: фоновые ролики загружаются из каталога `video`.

## Как опубликовать

1. Создайте на GitHub новый публичный репозиторий (например, `portfolio`).
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, остальные HTML-файлы, каталоги `css`, `js`, `img`, `video` и `.nojekyll`.
3. Откройте репозиторий → **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Дождитесь публикации. Сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Если репозиторий называется `ВАШ-ЛОГИН.github.io`, адрес сайта будет `https://ВАШ-ЛОГИН.github.io/`.

Видео уже включены и каждый файл меньше ограничения GitHub в 100 MB. Фоновое автовоспроизведение включено без звука (`muted`), потому что браузеры обычно блокируют автоматическое воспроизведение со звуком. На мобильных устройствах браузер может экономить трафик и не запускать фоновые видео автоматически.
